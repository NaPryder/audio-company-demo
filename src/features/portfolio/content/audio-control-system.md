## ภาพรวมโครงการ

งานนี้อยู่ที่ชั้นการควบคุม ไม่ใช่ตัวอุปกรณ์
เครื่องเสียงและภาพเดิมยังใช้งานได้ดี แต่กระจายอยู่หลายจุดและต้องเปิดตามลำดับที่ถูกต้อง
ผู้ดูแลที่เพิ่งเข้ามารับงานจึงใช้เวลานานกว่าจะเริ่มงานได้ และปิดระบบไม่ครบอยู่บ่อยครั้ง

## ขอบเขตงาน

- รวมการสั่งงานอุปกรณ์เดิมไว้ที่แผงควบคุมเดียว
- จัดลำดับเปิดและปิดระบบให้ทำงานอัตโนมัติ
- แยกสิทธิ์การเข้าถึงระหว่างผู้ใช้ทั่วไปกับผู้ดูแล
- ทำเอกสารสรุปการเชื่อมต่อสำหรับงานซ่อมบำรุงในอนาคต
